# Pedidos

Sistema de gerenciamento de pedidos desenvolvido com **Spring Boot** e **Maven**.

## 📋 Sobre

Aplicação backend para gerenciar usuários, produtos e pedidos através de uma API REST. O projeto utiliza banco de dados H2 para desenvolvimento e testes.

## 🛠️ Tecnologias

- **Java** 11+
- **Spring Boot** 3.x
- **Maven** 3.x
- **H2 Database** (desenvolvimento)
- **Spring Data JPA**

## 📦 Funcionalidades

- ✅ CRUD de Usuários
- ✅ CRUD de Produtos
- ✅ CRUD de Pedidos (Orders)
- 📝 Testes via HTTP Client
